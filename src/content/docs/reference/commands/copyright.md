Prints jkit's version, its copyright line and license (MIT), the website, and where to find the
licenses of the libraries built into the binary (`THIRD-PARTY-NOTICES`, next to the binary in the
release archives and in jkit's repository).

## Usage

```text
jkit copyright [-hV]
```

It changes nothing, never uses the network, and exits `0`.

## Options

| Option | Description |
| --- | --- |
| `-h`, `--help` | Show help and exit. |
| `-V`, `--version` | Print jkit's version and exit. |
